# 运行提示与排错

这是自由人工操纵，不需要数按键或按固定路线完成。问题出现时，优先保留本次输出目录中的 `summary.json`、`events.jsonl`、`manual.csv` 和控制台末段。

| 看到的情况 | 含义与处理 |
|---|---|
| 按方向没有动作 | 先点场景并按 7。只按住一个方向；切走窗口后先松开全部方向键，再重新按住。 |
| `JOG BLOCKED: ... ik_failed` | 当前候选目标未通过本地 IK 检查，未执行该段；松开后退回或换方向。不是已发生碰撞，也不能单凭一次拒绝证明位置全局不可达。 |
| `floor_margin` | 规划的携物间隙过小，先上抬再横移。6 仍可请求松爪；输入允许不保证松开的物体会留在盘内。 |
| 松键后还动一点 | 当前已执行小段会平滑走完。每个方向参考段最多 1.5 mm / 0.12 仿真秒；这不是实际停止距离保证。 |
| 按 6 没有立刻开合 | 当前段结束后执行最新开合意图；已有夹爪段最长 2 仿真秒。观察 `GRIPPER` 消息，不必反复按；反复按会切换最新目标。 |
| `grasp_or_transfer_not_verified` | 这是旧版评分锁提示。当前版本已移除；确认入口和冻结代码版本，不要回到高处补一套指定动作。 |
| `unexpected_contact` / `object_slip_stop` | 运行记录检测到非预期接触或滑落而停止。保存当前记录，具体原因以接触几何和状态为准，不继续把本回合当成成功。 |
| 方块已在托盘，却未显示通过 | 观察夹爪是否脱离、整块是否在盘内、是否由盘底支撑并低速稳定。评分需要连续 2 仿真秒；仅中心在盘内或刚松爪不够。 |
| 按 9 后显示 `partial` | 正常保存了尚未满足完整任务条件的回合。`user_9` 表示人工结束，不等于程序崩溃。 |
| 窗口闪退 / 退出码 `-1073741819` | 保存控制台与输出目录。旧开发阶段曾出现原生退出；当前三次功能复验通过不代表所有 Windows/驱动组合均无此问题。不要用空曲线推断发生过运动。 |
| 图像没有曲线 | 检查 `steps` 和保存样本数。0 步 / 单样本只能说明初始化状态，无法证明动态行为。 |
| 中文路径被显示为乱码、绘图找不到文件 | 当前绘图入口用 UTF-8 数据与明确编码的路径传递；避免混用旧脚本。保留数据，可单独重绘，不必重跑抓放。 |

本版保留关节限位、参考速度、环境间隙、实际接触和力矩限制。若同一方向被拒绝，程序保持当前参考，不会后台自动积压动作。外部焦点、计算和渲染会使现实操作慢于仿真时间；不建议通过放大物理步长或取消检查来“加速”。

现有证据只覆盖保存的机器、依赖、模型与三次同初态运行。换机器或修改场景后，需重新判断兼容性和任务结果；可复现入口不等于跨平台运行已经验收。
