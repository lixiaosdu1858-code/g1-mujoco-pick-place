# 独立入口的核验

核验日期：2026-10-21。包版本：v0.1.0 本地候选。

三次人工抓放成功发生在原项目入口。整理为独立目录后，先完成下列静态等价检查；随后用户在2026-10-21亲自通过新入口完成一次完整动力学抓放，详见[入口运行审核](candidate-user-verification.md)。助手整理和审核过程中没有新增仿真运行。

## 打包改变了什么

- `runtime/manual_pickplace.py` 的 `setup` 改为读取包内冻结场景、配置与初态。`main` 仅调整文件快照和来源记录，不再依赖多轮历史输出目录。
- `runtime/package_runtime.py` 是新增的初始化与快照适配层；只在新建模型时设置初态，不在运行中覆盖机器人或方块状态。
- `runtime/lesson_common.py` 将项目根目录、解释器校验和缓存校验改为可移植路径。`Run.ps1` 可选择包内虚拟环境或显式指定的已有独立环境，不安装软件。
- `cartesian_keyboard_target.py` 只替换基线索引与锚点文件的路径、哈希常量，其全部函数和类保持一致。
- 配置中的原机绝对路径已改为来源标识。模型XML和网格字节未改动；控制参数、求解器参数、关节限位、碰撞几何和评分阈值保持原样。

23个原有依赖模块中，20个文件与原项目逐字节一致。另3个为上面列出的存储/入口/路径适配。人工输入、夹爪控制、参考轨迹生成、逆运动学、动力学控制与任务评分函数均通过语法树对照。源文件SHA与对照范围保存在 `configs/source_equivalence.json`。

另附原记录绘图入口 `tools/Show-Result.ps1` 与 `runtime/plot_manual_task.py`。已用第一回合真实数据的独立副本完成 `-NoShow` 重绘；数据审计和绘图主体与原版相同，仅调整路径、解释器与缓存参数。该检查没有重跑仿真，也没有修改原始数据。对照记录见 `configs/plot_source_equivalence.json`。

`configs/reference.json` 约8MB，保留原空手静态参考的数值和哈希链；在本版人工操纵中仅作为规划器的来源核验材料，不作为自动动作路线执行。未打包历史大CSV、原项目日志、共享环境或总控脚本。

## 结论边界

这些静态检查确认路径整理没有改变已对照的模型与控制/规划逻辑。新入口用户运行另外提供了本机一次完整动力学证据；这不证明全部工作空间可达，也不是实机安全、自主抓放或另一台电脑安装验收。

当前源码材料为遵守许可边界，排除了两份派生场景XML。原创生成器读取使用者另备的固定输入，生成哈希与已验证场景完全相同的文件；控制程序、模型参数与运行配置不因此重新调参。生成器字节一致性与来源信息见[模型准备](scene-preparation.md)。
