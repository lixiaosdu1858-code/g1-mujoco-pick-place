在已有隔离环境及已配置的工作盘缓存中运行：

```powershell
& $g1Python -B .\tools\check_package.py
```

检查器使用递归允许清单，拒绝符号链接/目录联接、非预期文件、私有绝对路径和不允许的 XML。示例按自己的精确清单核对。允许本地存在且哈希正确的 `assets/scene.xml` 与 `configs/scene.xml`，但将其排除于源码清单及 ZIP。

维护者在审阅改动后使用 `--write-manifest` 重建 `PACKAGE-MANIFEST.json`；`--archive` 将清单内文件写入包目录外的新 ZIP，拒绝覆盖已有压缩包。文件清单通过只确认分发材料，不代表开窗或动力学成功。
