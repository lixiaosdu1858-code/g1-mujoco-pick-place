# 包内绘图入口验证

`tools/Show-Result.ps1` 可读取包内 `outputs` 下的新回合。它支持 `-RunPath`、`-Python`、`-CacheDirectory`、`-NoShow`；只读取保存的数据并生成 PNG 和来源 JSON，不启动 MuJoCo、不推进物理。

绘图解析器由原 `plot_manual_task.py` 移植，所有数据验证、数值转换、缺失值处理和采样函数保持一致。PowerShell 渲染器从准备绘图载荷到八面板生成、来源留证的主体保持一致，仅调整包根目录、解释器、缓存与子脚本位置。原来源哈希和适配后哈希保存在 [验证摘录](../evidence/plot-verification.json)。

2026-10-21 使用 Windows PowerShell 5.1、现有隔离环境和 E 盘缓存，在包含中文的包路径下以 `-NoShow` 检验第一成功回合的数据副本。原始及副本 summary/CSV 哈希一致，读取 16,345 行并绘制 16,345 行；新 PNG 与原来成功图的 SHA-256 完全一致。

生成图已实际查看：XYZ 位移、跟踪、指关节/接触力、物体高度、相对滑移/转角、落盘时长八个面板均完整；中文路径在 Python 与 PowerShell 之间传递正确。此测试没有打开图形窗口，也没有产生新机器人试验。工具测试副本与生成产物保留在本地诊断目录，排除于发布压缩包之外。

原样成功图仍见 [三回合结果](results.md)。绘图中的成功标签引用运行时保存的结果，重新生成曲线不会提高任务验收等级。
