# 位置与朝向对比的口径

根入口 `Show-ReplayComparison.ps1` 与 `Show-OrientationComparison.ps1` 支持 `-RunPath`、`-Python`、`-CacheDirectory`、`-NoShow`。它们只读取已保存记录，生成统计、PNG 和来源 JSON，不推进物理，不更改结果字段。

原工程三组位置图已逐项核对图像、载荷、统计、渲染器及源记录的哈希；完整新格式配对的用户朝向图也已核验。可迁移工具的检查与新包动力学验收分别记录，见[包验证](package-verification.md)。

## 位置图

按整数物理步对齐共同保存区间，使用同一个示范起点作为世界 XYZ 位移零点。统计使用全部对齐状态；显示可以抽点，保留端点、离散事件和极值。没有平滑、插值、时间拉伸或补造缺失尾部。

工具实际位置相对当前 FK 参考的误差是控制跟踪误差；回放实际轨迹相对示范实际轨迹的差是重放差异。两条实际曲线重合时，控制跟踪误差仍可能非零。

## 朝向图

四元数按 wxyz 读取，检查有限值与单位长度；q 与 −q 表示同一朝向。前六幅图显示工具和方块相对**同一个示范初始朝向**的世界轴旋转向量，单位为度，不是欧拉角。接近 180° 的主值分支需按工具的断线标记阅读，不能把跳变误读为突然转动。

末行分别给出工具、方块的两次实际朝向角距离，以及工具相对当前控制参考的跟踪角误差。第二组完整覆盖 62.240 s / 15561 状态，两次实际朝向角距离均为 0；工具跟踪角误差峰值约 0.513°，方块自身相对起点最大旋转约 21.145°。

旧格式没有完整四元数时，朝向工具报缺字段，不能绘成零差异。源数据校验失败、时轴缺口或已声明哈希不符时，应保留原件查明原因。
