# G1 人工键盘抓放 · v0.1.0

在 Windows + MuJoCo 中，用键盘操纵固定身体的 G1 单臂，把桌面方块抓起并放入托盘。方向由操作者决定，夹爪通过真实接触夹持方块；成功判定来自仿真状态。

## 开始运行

已验证的原工程环境为 Windows、Python 3.13.9、MuJoCo 3.3.7、NumPy 2.3.5。包内不附带 Python 环境；启动脚本不会安装或下载软件。依赖版本列在 requirements 文件中。

先按[模型准备](docs/scene-preparation.md)生成缺省不附带的场景。只有源码与网格、没有场景输入时，不能直接启动仿真。场景生成工具只读取本地输入，不下载文件。

准备好场景后，在本包目录打开 **Windows PowerShell 5.1**（`powershell.exe`），使用已经准备好的 Python 环境：

```powershell
.\Run.ps1 -Python '你的环境路径\Scripts\python.exe'
```

如果 Python 环境就在本包的 `.venv` 中，可直接运行 `./Run.ps1`。把项目与环境放在有空间的工作盘；输出与可控缓存默认写入本包目录。具体输出结构及静态验证见 [包验证说明](docs/package-verification.md)。

只检查文件、模型与初态时，给同一命令加 `-Inspect`；该模式不打开窗口、不推进物理。环境准备、静态检查、实际开窗和完整任务成功是分别记录的步骤。

## 怎么操作

先点击仿真窗口，再按键。无需固定次数或预设路线。

| 按键 | 功能 |
| --- | --- |
| 7 | 开始 |
| ↑ / ↓ | 沿世界 +X / −X 移动 |
| ← / → | 沿世界 +Y / −Y 移动 |
| PageUp / PageDown | 沿世界 +Z / −Z 移动 |
| 6 | 请求闭爪 / 开爪；当前短运动段结束后优先执行最新请求 |
| 8 | 切换相机 |
| 9 | 结束并保存记录 |

按住单个方向持续移动，松开后减速停止；相机旋转不会改变世界坐标方向。将夹爪移到方块两侧，按 6 夹住、抬高、移到托盘上方，再按 6 松开。稳定落盘后按 9 保存。

开合爪不受“抓取/搬运是否得分”限制。方向运动仍检查关节、速度和几何条件；边界处可能拒绝继续移动。保护停止、主动退出和成功都有独立记录，不会自动重试。

## 查看本回合结果

按 9 结束后，终端会打印 `MANUAL RUN` 目录。目录保存 `summary.json`、`manual.csv`、输入事件与参考记录。将下面的目录名替换为实际编号，可从保存数据生成曲线：

```powershell
.\tools\Show-Result.ps1 -RunPath '.\outputs\manual_user_实际编号' -Python '你的环境路径\Scripts\python.exe'
```

该工具只读取已有记录；使用 `-NoShow` 可直接保存 PNG 而不打开图窗。失败或提前结束的记录也保留真实状态，不会通过绘图把它变成成功。[绘图验证](docs/plot-verification.md)使用已有成功记录完成，未新增物理试验。

## 已经得到什么结果

三回合均由用户自由操纵，真实完成夹持、抬升、搬运、松爪与稳定落盘。三次初态与 24 项关键配置一致，84 项源码/资产快照一致；操作路径与时长不同。

| 回合 | 仿真时长 | 最大位置跟踪误差 | 连续有效落盘时间 | 完整人工任务 |
| --- | ---: | ---: | ---: | --- |
| 175535_099 | 65.376 s | 2.887 mm | 3.136 s | 通过 |
| 212238_372 | 83.888 s | 2.810 mm | 10.896 s | 通过 |
| 212557_670 | 46.304 s | 2.709 mm | 4.080 s | 通过 |

位置误差是实际夹爪位置相对当前关节参考的正运动学位置之差的模长。三次均满足原任务 3 mm / 0.05 rad 跟踪门槛及连续 2 s 落盘门槛，未记录非预期接触。这些结果对应当前固定模型、初态与桌面布局。
