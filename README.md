# G1 MuJoCo Pick-and-Place

Keyboard-controlled pick-and-place with a fixed-base Unitree G1 in MuJoCo.

在 Windows + MuJoCo 中，用键盘操纵固定基座 G1 的单臂，将桌面方块抓起、移动并放入托盘。操作者决定运动方向和松爪时机，方块通过接触、摩擦与重力运动。

**当前状态：v0.1.0 发布准备。** 原工程已完成三次独立启动的人工抓放复验；本地候选运行包已整理。本仓库首批提交展示项目说明和真实结果，运行代码、配置及模型尚未上传，许可证与模型来源仍在核对。当前内容尚不能直接启动仿真，也尚未发布 v0.1.0 Release。

## 已实现的任务

- 按住方向键连续调整夹爪的世界坐标 X/Y/Z 位置，松开后停止续接移动。
- 用 6 键控制开合爪，开合权限与任务评分分离。
- 完成夹取、抬升、搬运、主动释放与稳定落盘。
- 保存状态、输入事件和曲线，从实际接触、位姿与落盘状态判断结果。

控制链为：键盘输入 → 末端目标 → 有界逆运动学 → 平滑关节参考 → PD 与重力补偿 → MuJoCo 接触动力学。当前版本由人工控制，不包含自主抓放或学习策略。

## 操作方式

以下说明对应已验证的本地实现；完整运行文件上传后将补充安装与启动步骤。

| 按键                   | 功能                          |
| -------------------- | --------------------------- |
| 7                    | 开始                          |
| 按住 ↑ / ↓             | 世界 +X / −X 移动               |
| 按住 ← / →             | 世界 +Y / −Y 移动               |
| 按住 PageUp / PageDown | 世界 +Z / −Z 移动               |
| 6                    | 请求闭爪 / 开爪，当前短运动段结束后优先执行最新请求 |
| 8                    | 切换相机                        |
| 9                    | 结束并保存                       |

坐标方向不随相机转动。方向运动保留关节限位和几何检查，超出条件的参考会被拒绝。已验证原工程环境为 Windows、Python 3.13.9、MuJoCo 3.3.7、NumPy 2.3.5；接触求解设置为 `noslip_iterations=3`。
